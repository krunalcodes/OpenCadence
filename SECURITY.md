# Security Policy

OpenCadence handles contact data and email provider credentials, so security
reports are taken seriously.

## Reporting a vulnerability

Do not open a public issue for security problems.

Report privately through GitHub: open the repository's **Security** tab and
choose **Report a vulnerability**. Include:

- what the issue is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- the version or commit you tested

You will get an acknowledgement, and a fix or mitigation plan will be shared
with you before any public disclosure.

## Supported versions

The project is pre-release. Only the latest commit on `main` receives security
fixes.
